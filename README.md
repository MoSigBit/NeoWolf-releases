# NeoWolf releases

Downloads for the NeoWolf builder, and the inputs its toolchains are made from.
The game itself is at MoSigBit/NeoWolf.

- **builder-inputs**: the pinned sources, packages and soundfont the builder's runtimes use
  (and the MIDI soundfont, GeneralUser GS, with its licence), each as its lock files pin it.
